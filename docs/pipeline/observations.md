# Observation history

Source's `observations.ts` stores minimized profile-local history: listing IDs, source versions, observation times and fixed run status. It does not store ad text. An observation is not review completion, feedback or evidence of delivery. Loading a dashboard does not start observation capture.

The retained CLI has no standalone observation capture command. See [Source](nav-reader.md) and the [module map](../architecture/module-map.md) for ownership.
